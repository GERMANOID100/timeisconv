# Telegram TimeBot

Telegram-бот для сравнения текущего времени между двумя городами.

## 🧠 Возможности

- 🌍 Выбор двух городов из списка (или ввод вручную)
- 🕐 Отображение времени в обоих городах (24ч и 12ч)
- 📅 Показ даты и дня недели
- 🧮 Автоматический расчёт разницы во времени
- ✅ Подсветка текущего часа
- 📊 Генерация таблицы сравнения на 24 часа вперёд
- 🔄 Возможность смены городов или повтора сравнения
- 🌐 Переключение языка командой `/lang`

## 🚀 Быстрый запуск на Railway

1. Клонируй или загрузи этот репозиторий на GitHub.
2. Перейди на [https://railway.app](https://railway.app) → **New Project** → **Deploy from GitHub**
3. Укажи переменные окружения:

| Name       | Value                        |
|------------|------------------------------|
| API_TOKEN  | токен от [@BotFather](https://t.me/BotFather) |

4. Railway сам установит зависимости и запустит проект.


## 🧪 Команды бота

- `/start` — выбрать города
- `/lang` — переключить язык
- Автоматически после выбора городов бот:
  - Показывает разницу
  - Строит таблицу сравнения на 24 часа
