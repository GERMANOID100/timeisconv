# Timezone Comparison Telegram Bot

Этот Telegram-бот позволяет выбрать два города и сравнить текущее время и разницу между ними. Подходит для деплоя на [Railway](https://railway.app).

## 📦 Функции

- Выбор первого и второго города из предложенного списка
- Показывает:
  - Текущее время в каждом городе
  - Смещение от UTC
  - Разницу во времени
- Кнопки: "Повторить сравнение", "Сменить города"
- Поддержка выбора по UTC-смещению

## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone https://github.com/yourusername/timebot.git
cd timebot
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Укажи переменные окружения

Создай `.env` файл или задай переменную `BOT_TOKEN` с токеном бота от @BotFather.

### 4. Запусти локально

```bash
python bot.py
```

## ☁️ Деплой на Railway

1. Импортируй проект в Railway
2. В настройках проекта добавь переменную окружения:

```
BOT_TOKEN=<твой_токен>
```

3. Railway сам определит язык (Python) и запустит бота
