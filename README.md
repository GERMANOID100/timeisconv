# Telegram TimeBot

Этот Telegram-бот позволяет сравнивать текущее время между двумя выбранными городами.

## 🌍 Возможности

- Выбор двух городов из списка.
- Показ текущего времени в каждом.
- Расчёт разницы во времени.
- Удобный интерфейс с inline-кнопками.

## 🚀 Запуск на Railway

1. **Склонируй или загрузи этот репозиторий на GitHub.**
2. Перейди на [https://railway.app](https://railway.app) и создай новый проект.
3. Выбери опцию **"Deploy from GitHub"** и подключи этот репозиторий.
4. Установи переменную окружения:

   | Name       | Value                        |
   |------------|------------------------------|
   | `API_TOKEN` | Токен от [@BotFather](https://t.me/BotFather) |

5. Railway сам установит зависимости и запустит бота.

## 🛠️ Зависимости

Устанавливаются из `requirements.txt`:

aiogram
pytz

## 🧠 Пример использования

1. Введите команду `/start`
2. Выберите два города из предложенного списка.
3. Бот покажет текущее время в каждом и разницу между ними.
